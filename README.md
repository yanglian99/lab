# Red Alert Game

A small browser arcade game where you defend your command core through a 90-second red alert.

## Play locally

Open `index.html` in a browser, or serve the folder with any static web server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls

- **Arrow keys / WASD**: Move the defender
- **Space / Enter**: Pulse blast nearby drones
- **P**: Pause or resume
- **Restart button**: Start a new alert

## Goal

Intercept incoming drones before they reach the command core. Survive until the alert timer ends to win.
