lab
===

Mini Doom Lab is a lightweight browser FPS inspired by classic ray-cast shooters.

## Run locally

Because the project is plain HTML/CSS/JS, you can launch it with any static file server. For example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173` in a browser.

## Controls

- `WASD`: move
- `Mouse` or `← →`: look around
- `Shift`: sprint
- `Space`: shoot
- `R`: restart the arena
