# Sector Command: Crystal Frontier

A StarCraft-inspired browser strategy game prototype built with plain HTML, CSS, and JavaScript.

## Play

Open `index.html` in a browser, or serve the folder locally:

```bash
python3 -m http.server 4173
```

Then visit <http://127.0.0.1:4173>.

## Controls

- Click or drag-select friendly units.
- Right-click crystals or gas to gather resources.
- Right-click open terrain to move selected units.
- Press `A`, then click the battlefield to issue an attack-move command.
- Use the command console to train drones, rangers, and siege walkers.

## Goal

Gather resources, grow your army, defend your base, and destroy the enemy hive.
