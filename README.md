lab
===

StarForge Command is a lightweight browser RTS inspired by StarCraft. Open `index.html` in a browser to play.

## Features

- Resource harvesting with autonomous drones.
- Unit production for drones, marines, medics, and supply depots.
- Enemy waves that scale over time.
- Win/lose states centered around your base and the enemy hive.
- Canvas-rendered battlefield with unit selection and right-click movement.
