# Minecraft Builder Lab

A tiny Minecraft-inspired browser sandbox built as a single static page.

## What it includes

- A 16×16 editable block grid
- Seven block types: grass, dirt, stone, water, wood, leaves, and sand
- One-click world generators for terrain, a tree, and a lake
- Double-click erasing back to sky tiles
- Simple build stats for the selected block and placed block count

## Run locally

Because this project is static, you can open `index.html` directly in a browser or serve it with a tiny local web server.

### Option 1: open the file

Open `index.html` in your browser.

### Option 2: use Python

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
