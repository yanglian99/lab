## Island Siege

This repository now contains a lightweight browser strategy game inspired by beach-assault base raiding games such as Boom Beach.

### How to play

1. Open `index.html` in a browser.
2. Click the beach to deploy troops.
3. Use artillery to damage defenses before your troops advance.
4. Use medkits to heal groups of troops during the push.
5. Destroy the enemy HQ to win the raid.
