# Red Alert

Red Alert is a lightweight browser defense game built with plain HTML, CSS, and JavaScript. Intercept incoming drones before they hit the city core, keep base integrity above zero, and survive long enough to reach containment.

## How to play

1. Open `index.html` in a modern browser.
2. Click **Start Mission**.
3. Click or tap hostile drones before they reach the city skyline.
4. Reach a score of 600 to win. If integrity drops to 0%, the city falls.

## Files

- `index.html` defines the HUD and game board.
- `style.css` provides the futuristic Red Alert visual theme and responsive layout.
- `script.js` powers spawning, scoring, alert levels, pause/resume, and win/loss conditions.
