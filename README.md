# Rift Runner

A small browser-based retro arena shooter inspired by the speed and chunky style of classic shooters like Quake.

## Play

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls

- `W`, `A`, `S`, `D`: move and strafe
- `←`, `→`: turn
- Mouse movement: aim
- Click or `Space`: shoot
- `R`: restart

Survive waves of rift beasts, collect score, and use the minimap to keep moving through the maze.
