# Reading Game

A browser-based reading comprehension game for young learners. Players read short passages, answer multiple-choice questions, and build a score streak as they practice finding details and making inferences.

## Run locally

Open `index.html` in a browser, or serve the folder with:

```bash
python3 -m http.server 8000
```

Then visit <http://127.0.0.1:8000/index.html>.
