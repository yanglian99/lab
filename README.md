# RoboCode Arena

A tiny browser-based Robocode-inspired robot duel. Pilot the blue robot around a neon grid, rotate your turret, and trade shots with an autonomous red sentry.

## Play

Open `index.html` in a modern browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls

- `W`, `A`, `S`, `D`: move
- `Left Arrow`, `Right Arrow`: rotate turret
- `Space`: fire
- `Restart`: reset the match
